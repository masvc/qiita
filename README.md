## セットアップ
```bash
# Qiita CLIのインストール
npm install -g @qiita/qiita-cli

# ログイン
npx qiita login
```

## 記事の公開方法

GitHubにプッシュすると、GitHub Actionsが自動的にQiitaに反映します。
